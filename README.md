# 오늘 하루 Class — 지역 기반 원데이 클래스 예약 플랫폼

> 2025 구름톤 상반기 프로젝트 (1팀) · 2025.04.16 ~ 06.05

## 개요
인스타그램·블로그 등에 흩어져 있는 원데이 클래스 정보를 한곳에 모아, **내 위치 기준으로 오늘 참여할 수 있는 클래스**를 찾고 바로 예약할 수 있는 웹 플랫폼을 기획했습니다. 창작자는 별도 시스템 없이 클래스를 등록하고 예약을 관리할 수 있습니다.

## 기획 포인트
- **문제 정의**: 정보 분산, 수기 예약, 실시간 예약 가능 여부 확인 불가
- **핵심 기능**: 위치 기반 탐색, 실시간 예약, 결제, 창작자 클래스 등록
- **검증 계획**: 가설 설정 → 외부 설문으로 수요 검증 → 유저 스토리 작성 → 수익 모델 구체화
- **진행 관리**: 역할 분배, 기능 명세서, 마일스톤 수립
