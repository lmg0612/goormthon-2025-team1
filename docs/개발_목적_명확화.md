# 개발 목적 명확화 (팀 메모)

```
[개발 목적에 대한 명확화]
=> 스터디의 목적
=> 프로젝트의 완성도 (포폴 목적)
=> 2학기때의 경진대회의 수상의 목적

[아이디어에 대한 검증]
=> 가설 설정 / 사용자들에 대한 불편 해소 및 대상자 명확화와 수익성 계획 / 유저스토리 작성
=> 외부 대상자들을 통한 설문조사 ( 필요충분 검증_단계) / 가설 검증 
=> 후, 수익성 체계화 / 솜씨당 과 같은 비지니스 모델 
=> ex.
	지속적인 수입화 
	[ 즉, 사용자가 지속적으로 있어야 한다. ]
	(1) Consumer Social : ~25% is GOOD, ~45% is GREAT
	스냅챗, 트위터, 인스타그램과 같이 무료로 사용할 수 있고 광고를 비즈니스 모델로 가진 기업입니다. 기준은 가입자수입니다.

	Facebook : 60~70%(6 month)
	Instagram : 50~60%(6 month)
	Snapchat : 33%(3 month), 30% (24 month)
	Twitter : 31%(3 month), 22%(24 month)

[전체적인 프로젝트의 규모와 크기 설정]
=> 전체적인 규모와 크기를 정한다,
=> 역활분배와 기능명세서를 통해서 각자의 수행과제 선정 및 구체화
=> 마일스톤을 통해 중간중간 진행 일정을 명확화하고 프로젝트의 전체적인 진행여부 확인
```
